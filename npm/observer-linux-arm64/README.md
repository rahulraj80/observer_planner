# @superbased/observer-linux-arm64

The prebuilt **Linux arm64** binary (`bin/observer`) for
[`@superbased/observer`](https://www.npmjs.com/package/@superbased/observer), local-first
observability for AI coding agents.

You do not need to install this package yourself: `npm install -g @superbased/observer` pulls it in
automatically on Linux arm64 machines. Apache 2.0.
